# 需求与验收映射

附件是需求和样本来源；样本中的静态数据、图片和示例结果不作为本项目运行成果。

| 要求 | 实现与检查 | 证据或验证范围 |
|---|---|---|
| Python Windows 应用 | Tkinter 桌面版，源码入口与 Windows x64 打包 | Windows 11 实际启动与视频操作；Windows 10 需独立验收 |
| XLS/XLSX 与文本输入 | 文件独立选择与文本粘贴 | 附件覆盖两种文件；文本解析与导出回归 |
| 自动识别编号列 | 表头、统计形态、跨表覆盖率 | 10 组自动识别实跑；原文件和编号未公开 |
| 部分匹配 | 完全值优先，否则单向包含 | 独立反向不匹配断言 |
| 一对多、多对一 | 全部候选、最早参考行、稳定排序 | 回归中明确给定预期行序 |
| 未匹配行为冲突 | 提供置尾与固定原位两种策略 | 默认置尾；两种策略独立断言 |
| 新文件和格式保留 | XLSX 行片段移动；XLS 值型导出 | 样式、行高、列宽、其他部件字节和来源哈希断言 |
| 不损坏复杂表 | 公式、跨行合并风险区保护提示 | 范围见 README；复杂旧 XLS 对象不作完全保真保证 |
| 列识别98%、匹配95% | 缺少官方独立标注，不能据匹配率证明 | 附件实跑汇总及独立构造样例验证，不冒充官方准确率 |
| 已匹配排序正确率 | 独立规则基准与已知预期顺序 | 附件 10 组规则顺序比对及千行固定种子预期 |
| 千行≤1秒 | 5 次完整流程计时 | 中位0.291秒，本轮机器，非指定 i7 环境背书 |
| 72小时稳定 | 提供默认72小时可运行脚本 | 本轮180.05秒、3477轮、0异常；不宣称72小时已通过 |
| 本地隐私与180天日志 | 无联网处理，按月追加、不自动清理 | 核心源码及日志路径说明 |
| 演示真实性 | 实际录屏、同轮8/7/1/1与导出文件 | demo 下的字幕、实测记录和真实导出 |
| 申报与公开交付 | 本地完整信息、公开版匿名 | 公开包扫描后发布 Release |

附件记载的提前提交日期为2026年5月31日，早于本轮开发日期2026年10月15日；本项目不声称取得该时效加分。
