# 演示资料

`原始录屏.mp4` 是最终桌面版本的连续真实窗口录制，包含鼠标点击、路径输入、滚动、实际计算与实际导出；没有模拟界面或预制结果帧。`录屏事件.json` 是原始录制上的操作章节标记。

正式 MP4 通过 Release 单独提供。剪辑按章节调整原始操作速度并压缩等待时间，加入中文神经配音与同步字幕。应用处理图纸不调用语音服务；只有公开解说文字用于语音合成。

`本轮对齐成果.xlsx`、同名 `.audit.csv` 和 `.audit.json` 是最终录制中通过导出按钮直接产生的文件。本轮结果为 8 行、7 行匹配、1 行未匹配、1 行多候选；多候选包含在匹配行数内。

修改视频时可编辑解说词、SRT/ASS 和 `scripts/compose_demo.py`。从项目根目录运行前，将原始录屏复制到 `.private/video/raw.mp4`，将录屏事件复制到 `.private/video/events.json`；脚本调用公开旁白的语音服务后重组视频。仅编辑字幕可使用已有声音与常规视频编辑器重新套用字幕。完整旁白音轨也随演示资料提供。

正式文件的编码解码检查在 `validation/video_decode.txt`，时长和章节对应在 `视频实测记录.json`。模拟业务数据明确标注，运行成果来自程序实际执行。
